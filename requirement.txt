Problem Statement:
The COVID-19 pandemic accelerated the global shift toward e-commerce, reshaping consumer buying behavior and retail operations. Today’s retailers cannot rely solely on offering an online option but must provide personalized, user-friendly experiences. Consumers expect advanced search, personalized recommendations, and seamless shopping experiences. Moreover, highlighting region-specific local items is essential for strengthening local businesses.
This project aims to design and develop an Android/Web-based application that connects Customers, Retailers, and Wholesalers, streamlining the supply chain while enhancing user experience.
Objectives
• Build a platform for seamless interaction between customers, retailers, and wholesalers.
• Provide personalized search, filtering, and recommendations based on browsing/purchase history.
• Highlight region-specific local products.
• Ensure transparent pricing, real-time stock updates, and location-based shop suggestions.
• Enable robust order placement, payment (online/offline), and real-time order tracking.
User Hierarchy & Roles
• Customers:
o Browse/search/filter items
o Add to cart, place orders, make payments
o Provide feedback/raise queries
• Retailers:
o Manage inventory (add/delete/update items, set pricing)
o Track customers’ purchase history
o Place and manage orders with wholesalers
o Handle payments and customer queries
• Wholesalers:
o Manage inventory for retailers
o Set item pricing
o Maintain retailer purchase/transaction history
o Update stock after retailer orders
Functional Modules
• Module 1: Registration and Sign-Up
o Multi-role registration (Customer/Retailer/Wholesaler)
o Authentication via OTP
o Social logins (Google/Facebook)
o Google API integration for location
• Module 2: User Dashboards
o Category-wise item listing with images
o Item details: price, stock status, availability date
o Retailer’s proxy availability (retailer can show items available via wholesaler)
• Module 3: Search & Navigation
o Smart filtering (cost, quantity, stock availability)
o Location-based shop listings
o Distance filters for nearby options
• Module 4: Order & Payment Management
o Online and offline order placement
o Calendar integration for offline orders with reminders
o Order tracking: delivery details, status updates, notifications
o Automatic stock update after transactions
• Module 5: Feedback & Dashboard Updates
o Real-time order status updates
o Delivery confirmation via SMS/e-mail
o Product-specific feedback collection
o Feedback visible on item pages
Expected Outcomes
• A functional Android/Web e-commerce platform prototype
• Enhanced consumer experience with personalized search and localized product visibility
• Streamlined inventory/order management for retailers and wholesalers
• Improved feedback mechanisms for product/service quality
